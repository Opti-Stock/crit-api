# Auth and Roles

## Roles iniciales

- admin
- direccion
- recepcion
- coordinador
- medico
- terapeuta
- personal_acompanamiento
- paciente_familia

## Reglas iniciales

- Dirección y admin gestionan usuarios y roles.
- Recepción registra y consulta asistencia operativa.
- Médicos y terapeutas registran asistencia y nota médica.
- Coordinadores pueden gestionar calendario y citas.
- Personal de acompañamiento crea notas de enlace.
